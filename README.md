## 📚 Practicals Overview

| # | Practical | Key Concepts | Libraries |
|---|---|---|---|
| 1 | [Data Aggregation](./Practical_1_Data_Aggregation/) | groupby, sum, mean, count, multi-level | pandas |

| 3 | [PCA](./Practical_3_PCA/) | eigenvalues, covariance, explained variance | numpy, sklearn, seaborn |

| 7 | [Association Rule Mining](./Practical_7_Association_Rule_Mining/) | Apriori, support, confidence, lift | mlxtend |

## ⚙️ Setup

```bash
# Clone the repo
git clone https://github.com/YOUR_USERNAME/data-mining.git
cd data-mining

# Install all dependencies
pip install pandas numpy scikit-learn matplotlib seaborn mlxtend imbalanced-learn
```

---

## 🚀 Running a Practical

```bash
cd Practical_1_Data_Aggregation
python practical1.py
```
